隐私政策 / Privacy Policy

适用于由 ABCDabcde1098234 维护的 Toolathlon Eval 个人评测环境。生效日期：2026-10-28。

访问哪些数据

经用户 OAuth 授权后，应用按评测任务需要访问 Google Drive 文件内容与元数据、Google Sheets 工作表及单元格、Google Forms 表单结构和内容。所请求的授权范围为 Drive、Forms 表单内容和 Sheets 表格读写。任务可能创建、复制、编辑或删除指定的评测文件。

数据如何使用

数据用于准备评测任务、向模型提供任务上下文、执行工具操作以及检查任务结果。任务内容和工具返回数据会由操作者配置的模型服务及相关工具处理。当前模型服务由操作者自行部署。本应用不将 Google 用户数据用于广告、出售或训练通用人工智能模型。

存储与保留

OAuth 凭据保存在操作者的评测环境中，不发布到本网站或公开代码仓库。任务输入、模型回复、工具输出和评分日志可能保存在评测服务器，直到操作者删除。Google 中的任务文件会保留到任务清理流程或账号持有人将其删除；将文件移至回收站不代表立即永久删除。

共享与第三方

Google 数据通过 Google API 传输。评测任务调用的模型、工具或外部服务按操作者的配置参与处理相关任务数据。此说明网站由 GitHub Pages 托管；GitHub 可能为安全目的记录访问者 IP 地址，详见 GitHub 隐私声明。网站页面不包含广告或自建跟踪脚本。

撤销授权与删除

账号持有人可在 Google 账号的第三方连接中撤销访问权限。撤销授权不会自动删除已有评测日志或 Google 文件；操作者需分别清理服务器记录、OAuth 凭据、Google 文件及回收站。删除或隐私问题请联系 daiyingweir@gmail.com。

Google 数据使用承诺

本应用使用 Google API 获得的信息遵守 Google API Services User Data Policy，包括 Limited Use 要求。若数据处理方式发生变化，本政策应在启用该变化前更新。

English summary

Toolathlon Eval is a personal evaluation setup. With OAuth consent it accesses Drive files, Sheets spreadsheets and Forms needed by evaluation tasks. Data is processed by the operator's configured model and tools; the current model endpoint is self-hosted. Evaluation inputs, outputs and logs may remain on the operator's server until deleted. OAuth credentials are kept in the evaluation environment and are not published on this website. Google user data is not sold, used for advertising, or used to train general-purpose AI models. Revoking Google access does not automatically delete existing logs or task files. Contact daiyingweir@gmail.com for deletion or privacy questions. Use of Google API data follows Google's API Services User Data Policy, including Limited Use requirements.
